Overview

A full-cycle data analytics project on the publicly available Olist Brazilian E-Commerce dataset (Kaggle). The project covers data cleaning, exploratory data analysis across six business dimensions, customer segmentation with RFM, and ten SQL queries demonstrating advanced window functions and CTEs.

The goal is to surface actionable insights a growth or operations team could act on — not just descriptive statistics — with every finding backed by reproducible code.

Notebooks

01 · Data Cleaning

Joins seven Olist CSV files into two analysis-ready dataframes. Key decisions: filter to delivered orders only (96,469); use customer_unique_id (not customer_id) for person identity; resolve 764 duplicate review IDs across orders and 543 duplicate order submissions; fill null product categories with 'unknown' rather than dropping (products still have real sales data).

03 · SQL Analysis (DuckDB)

Ten queries written in DuckDB, executed in-notebook against the cleaned CSVs. No external database required.

#QuerySQL concepts used
Q1Monthly revenue + MoM growthCTE, LAG()
Q2Rolling 3-month averageAVG() OVER (ROWS BETWEEN 2 PRECEDING …)
Q3Quarterly revenue + QoQ growthPARTITION BY, CASE WHEN, % of year
Q4Top 10 customers by LTVRANK() on two dimensions, DATEDIFF, SUM() OVER ()
Q5Repeat vs one-time revenue split3 chained CTEs, window-function percentages
Q6Days between 1st and 2nd purchaseROW_NUMBER() OVER PARTITION BY, distribution buckets
Q7Revenue rank within categoryRANK() + DENSE_RANK(), nested windows

How to Run

All notebooks run on Google Colab (no local setup required).

1. Get the data

Download the Olist dataset from Kaggle and upload to your Colab session or mount Google Drive.

2. Run in order

01_Olist_Sales_Cleaned.ipynb   # generates clean/master_orders.csv + master_products.csv
02_Olist_Sales_EDA.ipynb        # reads from clean/; generates rfm_segments.csv
03_Olist_SQL_Analysis.ipynb     # reads from clean/; requires duckdb (pip install duckdb)

Dataset

Brazilian E-Commerce Public Dataset by Olist — available on Kaggle under a CC BY-NC-SA 4.0 licence. The dataset covers ~100k orders placed on the Olist marketplace between 2016 and 2018, including order status, price, payment, freight, customer location, product attributes, and customer reviews.

Note on scope: EDA uses master_orders_stable (Jan 2017–Jul 2018), which excludes the soft-launch period and the incomplete final month. SQL queries run on the full master_orders.csv (89,851 rows). The 97/3 repeat-buyer split is consistent across both scopes.
